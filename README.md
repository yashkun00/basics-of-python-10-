# OOPS CONCEPT
## 1.__str__()

Remember
__str__() must always return a string.

Without it, Python shows the default object representation with identity/address-like information.

## 2. Instance method
Uses self → works with one specific object.
Here:
self refers to s1
It accesses that object's data.

## 3. Class method
Remember
cls refers to the class (Bank)
Used mainly to modify class variables
Changes are visible to all objects using that class variable.

## 4. Static method
Use static methods when the function is related to the class but doesn't need object or class data.




|Type | Parameter | Access |
|---|---|---| 
|Instance Method | self | Object data |
|Class Method | cls | Class data |
|Static Method | None | Neither object nor class |
